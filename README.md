# Mini-projet Debruitage d’image par SVD tronquee

## Description
Ce projet implémente une méthode de débruitage d'images utilisant la Décomposition en Valeurs Singulières (SVD) tronquée. L'algorithme ajoute du bruit gaussien à une image, puis la restaure en conservant uniquement les k plus grandes valeurs singulières. La qualité de restauration est évaluée via les métriques PSNR et MSE, permettant de déterminer le nombre optimal de valeurs singulières à conserver.
