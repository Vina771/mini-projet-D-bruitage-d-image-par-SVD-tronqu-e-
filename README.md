# mini-projet-D-bruitage-d-image-par-SVD-tronqu-e-
Tâches principales   Ajouter du bruit gaussien à une image.   Restaurer l’image par troncature des petites valeurs singulières.   Comparer quantitativement (PSNR, MSE) avant/après.   Tâche avancée (optionnelle)   Script en ligne de commande (avec argparse) pour ajuster dynamiquement le seuil de troncature.
